# §1.7. Reasonable Time for Purpose of a Commercial Transaction.
(1) Whenever the Commercial Code requires an action to be taken within a reasonable time, a time that is not manifestly unreasonable may be fixed by agreement.
(2) Whether a time for taking an action required by the Commercial Code is reasonable depends on the nature, purpose, and circumstances of the action.
(3) An action is taken reasonably if it is taken at or within the time agreed or, if no time is agreed, at or within a reasonable time.
