# § 101.3. Application of Code to ending and subsequent

proceedings.
This Code shall apply to all proceedings hereafter commenced. This
Code shall also apply to all further proceedings in pending matters
except to the extent that the court determines that application in a
particular pending proceeding would not be feasible or would work
injustice, in which event the former procedure applies. Proceedings
pursuant to law in a proceeding taken prior to the time this Code
takes effect shall not be rendered ineffectual or impaired by this
Code.
